# CSA Customer Consumption Hub

A single-page dashboard for Customer Success Architects to track Microsoft Copilot PRU and Agent consumption metrics across CSA-managed customers.

Built by David Liu, Customer Success Architect.

## What It Does

- Displays Copilot adoption and usage dashboards per customer
- Tracks PRU (Purchased Resource Unit) consumption alongside Agent MAU
- Designed for internal use during customer reviews and QBRs
